# Реализация TreeMap и BidiMap на Java

Учебный проект по ООП и структурам данных (Задача 5). Написал с нуля две коллекции на дженериках без использования готовых `TreeMap` или `HashMap` из стандартной библиотеки.

## Что реализовано

1. **`MyTreeMap`** — упорядоченная карта на основе **красно-чёрного дерева**.
   * Базовые операции: `put`, `get`, `remove`, `containsKey`, `clear`, получение отсортированных списков `keys()` и `values()`.
   * Навигация (`MyNavigableMap`): поиск минимума и максимума (`firstKey`, `lastKey`), поиск ближайших соседей (`floorKey`, `lowerKey`, `ceilingKey`, `higherKey`), а также получение подкарт по диапазону (`subMap`, `headMap`, `tailMap`).
   * Работает как с естественным порядком (`Comparable`), так и с переданным `Comparator`.

2. **`MyBidiTreeMap`** — двунаправленная карта (`MyBidiMap`), где уникальны и ключи, и значения.
   * Позволяет искать значение по ключу (`get`) и ключ по значению (`getKey`) за $O(\log n)$.
   * Чтобы не дублировать логику дерева, внутри хранятся два синхронизированных `MyTreeMap` (прямой и обратный).
   * Если добавить пару со значением, которое уже занято другим ключом, старая связь автоматически удаляется.
   * Метод `inverse()` возвращает обратную карту (`V -> K`), работающую поверх тех же деревьев без копирования данных.

## ООП и принципы SOLID

* **Разделение интерфейсов (ISP):** разбил контракты на базовый `MyMap`, навигационный `MyNavigableMap` и двунаправленный `MyBidiMap`, чтобы классы не реализовывали лишние методы.
* **Единая ответственность (SRP):** `MyTreeMap` занимается только хранением данных и балансировкой красно-чёрного дерева, а `MyBidiTreeMap` отвечает за согласованность прямой и обратной карт.
* **Открытость/закрытость и дженерики (OCP):** коллекции работают с любыми типами данных и поддерживают кастомную сортировку через `Comparator`.

## Файлы проекта

* `MyMap.java` — базовый интерфейс карты и вложенный интерфейс `Entry`.
* `MyNavigableMap.java` — интерфейс с навигационными методами и выборками по диапазону.
* `MyBidiMap.java` — интерфейс двунаправленной карты.
* `MyTreeMap.java` — реализация красно-чёрного дерева со вставкой, удалением, ребалансировкой и навигацией.
* `MyBidiTreeMap.java` — реализация двунаправленной карты на двух деревьях.
* `Main.java` — тесты (включая проверку инвариантов КЧ-дерева и стресс-тест против `java.util.TreeMap`) + консольный пример работы.
